## 3. 실제 자료와 가상 정책의 구분

- YES24 공개 안내에서 **참고한 영역**: 취소·환불, 예매 절차, 수령과 본인확인 등 고객지원 문서의 주제와 예외 유형.
- 티켓모아에서 **별도로 정한 가상 설정**: 자체 취소 마감 시각·수수료 표, 인증 잠금 횟수, 상담원 이관 조건, 가상 공연장 안내 등.
- YES24의 공개 안내에 기재되지 않은 티켓모아의 구체적 시간·횟수·금액을 YES24 공식 규정으로 인용하지 않습니다.

## 4. 자료 작성 및 저작권 유의사항

1. 초기 `knowledge/*.md` 문서는 AI로 작성한 가상 티켓 예매 정책을 바탕으로 했고, 이후 공개 안내의 관련 주제를 참고해 보강했습니다.
2. 외부 원문 전체나 원문의 표·이미지를 GitHub에 복제하지 않고 **원본 URL과 참고 주제만 기록**합니다.
3. 정확한 과거 열람 기록이 없는 경우, 본 출처 대장을 과거에 특정 페이지를 직접 열람했다는 증빙으로 표현하지 않습니다.
4. 이 출처 문서는 RAG에 색인하는 고객 안내 문서가 아닙니다. `docs/`에 보관하고 `knowledge/`와 분리합니다.
